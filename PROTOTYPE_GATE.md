# FYE prototype gate

Production is blocked until five people have played the core casting loop in
person. Automated tests, browser checks, and performance measurements do not
count as a playtest.

## Run the session

Use the smallest possible build: one generated layout with two waystones and
one hazard. Give each person the same prompt: “Reach the stones without
touching the hazard.” Do not explain elements, gestures, or controls unless
they ask. Let each person try three layouts, then ask “Again?”

## Decision

The decisive signal is whether anyone draws a second line without being
prompted. Review the five sessions before authorizing production. If nobody
does, return to the prototype instead of adding more interface or hand-tracking
work. Keep any recording optional and do not collect camera frames or hand
landmarks from the product.

This gate is intentionally unchecked: it needs five real people, not a test
run. See section 14 of `update.md` for the originating product rationale.
